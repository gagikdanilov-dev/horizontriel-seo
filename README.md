# Horizontriel — генератор статических SEO-страниц

Тянет опубликованные объекты из твоего PocketBase и собирает **реальные HTML-страницы**,
которые видят и Google, и Яндекс (в отличие от клиентского рендера на Тильде).

Что генерируется:

| Страница | URL | Под какой запрос |
|---|---|---|
| Хаб-каталог | `/` | «недвижимость в России и за рубежом» |
| Региональный тип | `/kvartiry/`, `/doma/`, `/uchastki/`, `/garazhi/` … | «купить квартиру в Ставропольском крае» |
| Город | `/gorod/kislovodsk/` | «недвижимость в Кисловодске» |
| Регион | `/region/stavropolskiy-kray/` | «недвижимость в Ставропольском крае» |
| **Город × тип** | `/gorod/kislovodsk/kvartiry/` | **«купить квартиру в Кисловодске»** ← самые конверсионные |
| Объект | `/obekt/{slug}/` | карточка с `RealEstateListing` + `Offer` |
| `sitemap.xml`, `robots.txt` | | для вебмастеров |

Хаб каталога индексируется, и его canonical указывает на собственный URL.
Городские страницы генерируются при наличии объектов. Пустые страницы типов, регионов и сочетаний «город × тип» получают
`noindex, follow` и исключаются из sitemap. То же правило действует для посадочных
страниц с пустой подборкой. Тексты и FAQ для кластеров используют данные объектов
(количество, диапазон цен, средняя площадь).

## 0. Быстрый локальный прогон

```bash
python3 build.py --sample     # соберёт dist/ на тестовых данных
# открой dist/index.html в браузере
```

Боевой прогон против реального PocketBase:

```bash
python3 build.py              # берёт PB_URL/коллекцию из config.py или из env
```

Python 3.9+ и стандартная библиотека; для календарных дат используется `Europe/Moscow` из системной базы часовых поясов. В CI — Python 3.12 / Ubuntu. Если локальный Python не содержит базы IANA (например, Windows), установите пакет `tzdata`.

Проверки без сети и без записей в PocketBase:

```bash
python -m unittest discover -s tests -v
```

Контракт международного выпуска и границы проверок: [INTERNATIONAL_RELEASE.md](INTERNATIONAL_RELEASE.md).

## 1. Домен (главный вопрос)

Тильда занимает `horizontriel.com`, поэтому статику вешаем на **поддомен**:

```
catalog.horizontriel.com   →   GitHub Pages
```

1. В `config.py` (или переменной `SITE_BASE`) укажи `https://catalog.horizontriel.com`.
2. У регистратора/DNS добавь CNAME-запись:
   `catalog` → `<твой-логин>.github.io`.
3. Файл `CNAME` в `dist/` генерится автоматически из `SITE_BASE`.

> Поддомен vs подпапка: подпапка (`horizontriel.com/catalog/`) чуть сильнее консолидирует
> вес, но на Тильде без reverse-proxy (Cloudflare Worker) её не сделать. Поддомен обе
> поисковые системы индексируют нормально — для старта берём его.

## 2. Публикация через GitHub

1. Залей папку в новый репозиторий.
2. **Settings → Pages → Source: GitHub Actions**.
3. **Settings → Secrets and variables → Actions → Variables** — добавь (по желанию,
   иначе возьмутся дефолты из `config.py`):
   - `SITE_BASE` = `https://catalog.horizontriel.com`
   - `PB_URL` = `https://api.horizontriel.com`
   - `MAIN_SITE` = `https://horizontriel.com`
4. Вкладка **Actions → Build & Deploy → Run workflow** — первый запуск вручную.

Воркфлоу пересобирает сайт **каждые 6 часов** и при изменении `build.py`,
`templates.py`, `config.py`, `ht_landings.py`, `geography.py`, `listing_contract.py`, `assets/**`, `tests/**` или файла воркфлоу в ветке `main`.
Частота плановой сборки задаётся в `cron`.

> Если у тебя закрыт публичный доступ к коллекции `listings` — добавь секрет
> `PB_TOKEN` и Authorization-заголовок в `fetch_listings()` (сейчас чтение идёт без
> токена, как на самом сайте).

## 3. Связь с Тильдой

HTML-блоки и SEO-настройки главного сайта редактируются в проекте Тильды.
Из каталога ссылки ведут в интерактивный каталог через `/#catalog` с фильтрами
в хеше. Посадочные страницы передают параметры `ht_lp` и `utm_content` в ссылках
на форму `#contact`.

Ссылки на страны до публикации новых страниц Tilda также используют существующий
`/#catalog?geo_country=...`; для Дубая добавлен `geo_city=Дубай` и страна ОАЭ.
`PUBLISHED_COUNTRY_PAGES` в `config.py` изначально пуст. Только после публикации
и проверки конкретной страницы добавьте её точный путь в этот набор, например
`frozenset({"/cyprus"})`. Остальные направления продолжат открывать каталог.
Пустой набор позволяет сначала выпустить SEO и резервные ресурсы карты без ссылок
на ещё не существующие `/cyprus`, `/turkey`, `/dubai`, `/spain`.

Перед публикацией правок на Тильде проверь фильтры каталога, открытие карточек
по `?object=id` и локальное поведение формы без отправки заявки и событий Метрики.
Реальные тестовые лиды не создавать. Для ссылок на статические карточки используй
существующие URL каталога из `sitemap.xml`.

## 4. Отправить в поисковики

Добавь **поддомен** (это отдельный сайт для вебмастеров) и загрузи sitemap:

- **Яндекс.Вебмастер** → добавить сайт `catalog.horizontriel.com` → Индексирование →
  Файлы Sitemap → `https://catalog.horizontriel.com/sitemap.xml`.
  Затем «Переобход страниц» для главной хаба и топ-кластеров.
- **Google Search Console** → добавить ресурс (URL-prefix) `https://catalog.horizontriel.com/`
  → Sitemaps → тот же адрес.

## Файлы

- `config.py` — источник PB, домен, карты типов/городов, транслитерация, формат цены.
- `templates.py` — HTML-шаблоны и CSS (в стиле основного сайта).
- `build.py` — загрузка, нормализация записей (как `pbToListing`), генерация, sitemap.
- `listing_contract.py` — страны, явная валюта, даты и безопасные URL файлов.
- `assets/vendor/` — закреплённые версии библиотек карты, изображения, лицензии и SHA-256 manifest.
- `sample_listings.json`, `sample_settings.json` — данные для `--sample`.
- `.github/workflows/build.yml` — сборка и деплой.

### География опубликованных объектов

На странице `/geografiya/` и в `/geografiya/cities.json` собраны населённые пункты по типам недвижимости. Генератор читает все страницы публичной коллекции `listings` и учитывает основной и дополнительные типы. Город входит в подборку, пока в ней есть хотя бы один опубликованный объект. Каталог обновляется по существующему расписанию GitHub Actions.

Для нового направления заполните `city` и `region`. Если в схеме есть `country`, генератор учитывает его отдельно. При работе с текущей схемой страну можно указывать в `region`, например «Турция». Существующие страницы Ставропольского края сохраняют адреса. Для остальных направлений каталог формирует страницы по фактическому местоположению и типу.
