## Поведение

- Видимый бренд — Horizontriel. Общий хаб и подвал показывают международные направления. Существующие региональные страницы, четыре SEO-посадочные КМВ, canonical и реестр постоянных URL сохраняются.
- Все опубликованные объекты получают отдельные страницы. Зарубежные города появляются в географии с разными URL для одноимённых городов разных стран; общий хаб показывает новые объекты из всего каталога.
- Списки, география, похожие объекты и SEO-посадочные сортируются по `published_at`, иначе по `created`, от новых к старым. При одинаковом времени — ID по возрастанию. `updated` не поднимает старую карточку.
- Для `published_at` выводится «Опубликовано», для старых записей с одним `created` — «Добавлено». Время сортировки и машинное значение — UTC, видимый календарный день — Europe/Moscow. Недостоверная/отсутствующая дата не выдумывается. JSON-LD содержит `datePosted` только для известной публикации; старым записям ставится `dateCreated`.
- `currency` принимает RUB/EUR/USD/AED/TRY. RUB по умолчанию допустим только для явно определённой России; неизвестная валюта показывается как «валюта уточняется», без ложного Offer/priceCurrency. Смешанные валюты не участвуют в общем минимуме/максимуме. Таблицы цен по комнатам разделены по валюте. Пересчёт не выполняется.
- `videos` — список имён файлов PocketBase, до трёх mp4/webm. Сегменты URL кодируются; внешние видео-URL и пути с переходом по каталогам не принимаются как имена файлов. Плееры используют controls, playsinline, preload=metadata, без autoplay. Первое фото используется как poster. Объекты только с фотографиями работают как прежде.
- JSON-LD экранирует `<`, чтобы текст не мог закрыть HTML script. Текст карточек продолжает экранироваться.
- Резервные Leaflet 1.9.4 и markercluster 1.5.3 копируются из `assets/vendor` в dist. Их первичные URL и SHA-256 записаны в manifest; сохранены лицензии и пять PNG. Сборка не скачивает зависимости.
- Страницы стран включаются по факту публикации: пустой `PUBLISHED_COUNTRY_PAGES` направляет посетителя в существующий `/#catalog?geo_country=...`, а Дубай — в ОАЭ/Дубай. Добавление проверенного пути в этот набор включает прямую ссылку только на эту страницу Tilda. SEO и резервные ресурсы карты можно выпускать раньше четырёх страниц без новых 404.

Проверяются все страны и валюты, региональные страницы, sitemap/canonical, даты и порядок, старые адреса после правки заголовка, плееры, безвредная HTML-строка, пагинация запроса и состав выходного артефакта с резервными ресурсами карты. ## Минимальный порядок выпуска

1. Создать release commit от фактического актуального main. Перед записью снова сверить его SHA; если бот успел дополнить реестр URL, сохранить новые записи. Не заменять ветку старым snapshot. Манифест этой подготовки не содержит изменений реестра относительно `ab3d9248`.
2. Выпустить SEO при пустом `PUBLISHED_COUNTRY_PAGES`. Сборка совместима с отсутствующими новыми полями: legacy даты и валюты обрабатываются явно, видео при отсутствии поля не выводится. Права/схему PocketBase генератор не меняет.
3. Проверить завершившийся Pages deployment: прежние canonical, отсутствие новых 404 и пять `/assets/vendor/...` URL карты вместе с изображениями Leaflet. Только после этого публиковать международную карту Tilda и её согласованный основной каталог/router.
4. Когда соответствующие Tilda-страницы опубликованы и проверены, добавить только их пути в `PUBLISHED_COUNTRY_PAGES` и пересобрать SEO. Наличие имён страниц в контракте не является доказательством публикации.

offline проверок прошли повторно. SHA-256 HTML:

Фактический формат видео и размер файла обеспечивает схема и путь загрузки; статический генератор не скачивает видео для проверки.
